# HabitHub – Release Notes

## Version 1.0 – Initial Release

**Release Date:** 5 November 2026

### Overview
HabitHub is an Android application designed to help users build positive habits, manage daily goals and monitor personal progress.

### Features Included
- User registration and login using Firebase Authentication.
- Google Sign-In.
- Create, edit and manage personal habits.
- Organise habits into categories.
- Set daily goals and custom habit frequencies.
- Select specific days for recurring habits.
- Set reminder times and receive notifications.
- Add notes to individual habits.
- Track habit completion and progress statistics.
- View achievements.
- Manage profile and application settings.
- Store user and habit information using Firebase Firestore.

### Technical Information
- Developed using Kotlin and Android Studio.
- Uses Firebase Authentication and Cloud Firestore.
- Uses Firebase Cloud Messaging for notifications.
- Includes unit and Android instrumented test source files.
- GitHub Actions automates the Android build and unit testing workflow.

### Build and Testing
The GitHub Actions workflow successfully completed the Android debug build and configured unit tests.

### Future Improvements
- Further enhancements to progress visualisation.
- Additional achievement features.
- Improved user experience and interface refinements.
